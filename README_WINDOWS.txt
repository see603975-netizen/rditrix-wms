Rditrix WMS Lite V6.9 - Windows 使用說明
==========================================

【第一次使用】
1. 安裝 Python：https://www.python.org/downloads/
   ※ 安裝畫面第一步務必勾選「Add python.exe to PATH」
2. 雙擊「啟動WMS.bat」
   （第一次會自動安裝介面套件，之後直接開啟）

【登入】
預設管理員帳號：PO001
預設密碼：123123
使用者姓名：輸入自己的名字（會記錄在操作紀錄）
※ 建議登入後到「帳號管理」重設密碼並建立各自帳號

【小螢幕】
畫面被切到時：系統設定 → 顯示縮放 → 選 100% → 儲存 → 重開程式

【資料】
所有資料存在同資料夾的 wms_system_v3.db。
要備份或搬移電腦時，整個資料夾複製走即可。
